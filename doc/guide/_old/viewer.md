# The Viewer

The viewer shows the **rendered result**. If the results are visual, it will show as a graphic. Otherwise, it will show
the data view.

![Screenshot of the Viewer](viewer-screenshot.png)

## Choosing what to view

What is displayed is defined by the function that is either selected or pinned in the [function list](guide:function-list).

For networks, the output is defined by the _rendered node_. This is the node with the small triangle in the bottom-right corner:

![The rendered node](viewer-rendered-node.png)

If you'd like to view a different node, **double-click** it in the network editor.

For code, the output is defined by the function's _return value_.

## Navigating the viewer

- You can **zoom** in and out by scrolling the mouse wheel.
- You can **pan** the view by dragging it with the left mouse button.
- You can **reset** the view by doubleclicking somewhere in the viewer.

Pan and zoom also work in the [network editor](guide:network-editor).

## Playing an animation

If your project uses animation, you can start and stop the animation by pressing the <button class="btn"><i class="fa fa-play"></i><label>Play</label></button>
button. Animations always start from frame 1.
