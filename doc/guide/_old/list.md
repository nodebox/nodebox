# List Operations

Lists are a core concept of NodeBox Live. We provide operations for creating, querying and modifying lists.

### Creating lists

[makeNumbers](ref:g.makeNumbers) — Make a list of numbers

[stringSplit](ref:g.stringSplit) — Split a string into substrings

[import](ref:g.import) — Import CSV data as a list of maps

### Getting items

[first](ref:g.first) / [second](ref:g.second) / [last](ref:g.last) — Take the first, second or last item

[rest](ref:g.rest) — Take all but the first item

[slice](ref:g.slice) — Take a portion of the list

[takeEvery](ref:g.takeEvery) — Take every nth element

[pick](ref:g.pick) — Grab random elements from the list

[randomSample](ref:g.randomSample) — Select random elements from the list

[switch](ref:g.switch) — Select one of the inputs

### Querying lists

[contains](ref:g.contains) — check if a list contains the item

[count](ref:g.count) — count the number of items in the list

### Combining lists

[combine](ref:g.combine) — combine multiple lists together

### Modifying the list

[cull](ref:g.cull) — Keep only items where the corresponding boolean is true

[distinct](ref:g.distinct) — Remove all duplicate items

[repeat](ref:g.repeat) — Repeat items in the list

[reverse](ref:g.reverse) — Reverse the order of items in the list

[shift](ref:g.shift) — Move items from the beginning to the end

[shuffle](ref:g.shuffle) — Randomize the order of items in the list

[sort](ref:g.sort) — Sort items in the list

### Maps / dictionaries

[zipMap](ref:g.zipMap) — Combine keys and values together in a map
