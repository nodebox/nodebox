# Animation

Animation in NodeBox Live is based on expressions based on the current time or frame.

### Current time

[frame](ref:g.frame) — get the current frame number

[elapsedTime](ref:g.elapsedTime) — get the elapsed time in seconds

### Waveforms

[sineWave](ref:g.sineWave) / [squareWave](ref:g.squareWave) / [triangleWave](ref:g.triangleWave) — generate different wave forms
