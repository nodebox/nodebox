# Sharing your Project

You can include NodeBox Live projects in your website or blog. To do so, you'll copy and paste a snippet of HTML code, just
like a YouTube video.

Click the <button class="btn"><i class="fa fa-share-square-o"></i></button> _Share_ button in the header
to bring up the _share dialog_:

![Screenshot of the Share Dialog](sharing-screenshot.png)

Changing the parameters automatically updates the code snippet.

- **Size** is the target size of the project. You can use pixel values (e.g. `800`) or percentages (e.g. `100%`).
- **Function** is the function to render. By default, this will be main, but depending on your project it might need
  to be set to something different.
- Check **Animate** to start animating the project as soon as it is loaded.
