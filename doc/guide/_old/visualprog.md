# A Visual Programming Language.

NodeBox Live is actually a visual functional progamming language, inspired by a number of textual functional programming languages, notably Clojure and Haskell.

In functional programming, the functions take a central role, transforming data from one representation to the next.

Note that in NodeBox Live, we haven’t really talked about classical object-oriented programming constructs such as classes and objects. Instead, the objects of NodeBox Live are really holding places for data. The functions take in the data and generate new data.

Internally, nodes have a reference to a function: a piece of code written in Javascript.
