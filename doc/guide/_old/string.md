# String Manipulation

NodeBox Live has support for performing operations on strings.

### Creating strings

[string](ref:g.string) — Create a simple string

[import](ref:g.import) — Import text from a TXT file

### Querying / lookup

[stringLength](ref:g.stringLength) — Give the length of the string

[wordCount](ref:g.wordCount) — Count the number of words in the string

[characterAt](ref:g.characterAt) — Take the character at the given index

[stringContains](ref:g.stringContains) — Check if the string contains the given text

[startsWith](ref:g.startsWith) / [endsWith](ref:g.endsWith) — Check if the string starts / ends with the given text

[stringEquals](ref:g.stringEquals) — Check if two strings are equal

### Combining

[concatenate](ref:g.concatenate) — Combine multiple strings

### Splitting

[stringSplit](ref:g.stringSplit) — Split the string into substrings

[toCharacters](ref:g.toCharacters) — Split the string into individual characters

[toWords](ref:g.toWords) — Split the string into words

### Manipulating

[stringReplace](ref:g.stringReplace) — Replace all occurrences of the text

[substring](ref:g.substring) — Take a portion of the string

[stringTrim](ref:g.stringTrim) — Remove spaces from the beginning / end

[toUpperCase](ref:g.toUpperCase) / [toLowerCase](ref:g.toLowerCase) / [toTitleCase](ref:g.toTitleCase) — Change characters to upper- or lower case.
