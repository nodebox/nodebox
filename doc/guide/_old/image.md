# Imaging

NodeBox Live has built-in support for importing, combining and filtering images.

### Generating images

[import](ref:g.import) — import an image from a file or URL

[colorImage](ref:g.colorImage) / [gradientImage](ref:g.gradientImage)

[toBitmap](ref:g.toBitmap) — convert a vector shape to an image

### Transforming images

[translate](ref:g.translate) / [rotate](ref:g.rotate) / [scale](ref:g.scale)

### Combining images

[blend](ref:g.blend) — combine two images using blending modes

[imageMask](ref:g.imageMask) — mask an image using another image

### Image filters

[blur](ref:g.blur) / [bump](ref:g.bump) / [crossEdges](ref:g.crossEdges) / [dent](ref:g.dent) / [emboss](ref:g.emboss) / [equalize](ref:g.equalize) / [findEges](ref:g.findEdges) / [glow](ref:g.glow) / [mosaic](ref:g.mosaic) / [pinch](ref:g.pinch) / [posterize](ref:g.posterize) / [solarize](ref:g.solarize) / [removeNoise](ref:g.removeNoise) / [lightTunnel](ref:g.lightTunnel) / [twirl](ref:g.twirl)

### Image statistics

[histogram](ref:g.histogram)
