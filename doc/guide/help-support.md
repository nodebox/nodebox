# Getting Help and Support

## NodeBoxGPT

To make working with NodeBox even easier, NodeBoxGPT is available as a custom ChatGPT model trained specifically for NodeBox. It can help with parsing files, creating visualizations, and providing guidance on using NodeBox effectively. While it's still growing in capabilities, NodeBoxGPT has been trained on all NodeBox documentation and understands the source code of all built-in NodeBox nodes.

Try it out: <a href="https://bit.ly/nodebox-gpt" target="_blank">NodeBoxGPT</a>.

## Found an Issue?

If you encounter a bug or have a feature request, please [open an issue](https://github.com/nodebox/live) on GitHub.
