# Welcome to NodeBox

NodeBox is a node-based application for generative design. It's a visual programming environment that allows you to create animations, illustrations, data visualizations, and more.

## What Can You Do with NodeBox?

With NodeBox, you can:

- Visualize data in innovative ways, transforming numbers into compelling visual stories.
- Design intricate illustrations, from geometric patterns to abstract art, with precision and flexibility.
- Generate procedural artwork, where rules and randomness combine to produce endless variations.
- Create dynamic animations with ease, using a system that intuitively links visual elements.

**Look at the [gallery](/gallery) to see examples of what you can create with NodeBox.**

## Concepts

At its core, NodeBox uses nodes—visual blocks that represent different elements, functions, and operations. By connecting these nodes, you build up a network that transforms simple inputs into sophisticated outputs. This modular approach gives you full control over every aspect of your design, while also allowing for spontaneous experimentation.
